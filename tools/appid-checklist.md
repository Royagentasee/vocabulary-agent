# AppID 申请流程清单

> 跟着这个清单走，每完成一项打勾。

## 阶段 1：准备资料（30 分钟）

- [ ] **企业 / 个人营业执照**
  - 个人：身份证 + 人脸认证
  - 企业：营业执照、对对号小额打款、法人身份证

- [ ] **联系邮箱**（未被微信注册过）

- [ ] **手机号**（接收验证码）

- [ ] **个人 / 法人身份证正反面**

- [ ] **对公账户**（仅企业，需要 1 元打款验证）

## 阶段 2：注册微信小程序账号（5 分钟）

- [ ] 访问 https://mp.weixin.qq.com/
- [ ] 点击「立即注册」 → 选「小程序」
- [ ] 填写邮箱、密码 → 邮箱激活
- [ ] 选择主体类型（个人 / 企业）→ 进入主体认证

## 阶段 3：主体认证（1-3 天）

### 个人主体（推荐 MVP）
- [ ] 身份证正反面
- [ ] 微信扫码人脸验证
- [ ] 等认证通过（即时）

### 企业主体
- [ ] 营业执照（彩色照片）
- [ ] 法人身份证（彩色）
- [ ] 对公账户（小额打款验证）
- [ ] 支付 300 元认证费
- [ ] 等审核（1-3 天）

## 阶段 4：填写小程序信息（10 分钟）

- [ ] **小程序名称**：Vocabulary Agent
- [ ] **小程序简介**：AI 个性化辅导型单词学习工具。FSRS 智能调度复习节奏，AI 实时拆词、考点分析，覆盖雅思/托福/GRE/SAT 核心词汇。
- [ ] **小程序头像**：512×512 PNG
- [ ] **服务类目**：教育 → 在线教育
- [ ] **小程序描述**：见下方模板

### 小程序描述模板
```
Vocabulary Agent 是一款基于 AI 技术的英语单词学习工具，专为备考雅思、托福、GRE、SAT 等高阶英语考试的学习者打造。

核心功能：
• FSRS 智能调度：基于最新间隔重复算法，精准预测遗忘曲线
• AI 私教拆词：调用大模型实时分析词根词缀、考点考频、记忆窍门
• 多模式背词：看英忆中、拼写听写、例句填空、AI 对话练习
• 错题本与可视化：记忆曲线、能力雷达、错词本可重考
• 跨端同步：Web / iOS / Android 学习进度实时一致

适用人群：
• 雅思 / 托福 / GRE / SAT 考生
• 想提升英语词汇量的进阶学习者
• 喜欢 AI 辅助学习的高效人士
```

## 阶段 5：填写 AppID（2 分钟）

- [ ] 登录 mp.weixin.qq.com
- [ ] 开发管理 → 开发设置 → 复制 **AppID(小程序 ID)**
- [ ] 修改 `apps/mini/project.config.json`：

```json
{
  "appid": "wx1234567890abcdef"  // ← 替换这里
}
```

## 阶段 6：获取密钥（5 分钟）

- [ ] 开发管理 → 开发设置
- [ ] 生成 **AppSecret（小程序密钥）**（用于服务端调用）
- [ ] 妥善保存，不要提交到代码仓库

## 阶段 7：配置服务器域名（可选，10 分钟）

如果需要让小程序调用 AI 网关：

- [ ] 部署 ai-gateway 到公网（云函数 / VPS）
- [ ] 域名需要 ICP 备案
- [ ] 开发管理 → 开发设置 → 服务器域名
- [ ] 配置 `request 合法域名`：例如 `https://api.vocab-agent.com`

## 阶段 8：编译 + 上传（30 分钟）

- [ ] 在 monorepo 根目录：

```bash
pnpm install
pnpm --filter @vocab-agent/mini build
```

- [ ] 下载并打开**微信开发者工具**
- [ ] 导入项目 → 目录选 `apps/mini/dist/`
- [ ] 确认 AppID 正确
- [ ] 点击右上角「上传」
- [ ] 填写版本号（1.0.0）+ 项目备注
- [ ] 上传成功 → mp.weixin.qq.com → 版本管理可见

## 阶段 9：准备上架材料（30-60 分钟）

### 5 张截图（750×1334 或更大）
- [ ] 首页
- [ ] 选词书
- [ ] 复习 - 显示释义
- [ ] 复习 - AI 解释
- [ ] 学习报告

可使用 `tools/submission/capture-screenshots.mjs` 自动生成。

### 隐私协议
- [ ] 已在小程序内显示（pages/legal/privacy-policy）
- [ ] 在 mp.weixin.qq.com → 设置 → 基本设置 → 服务条款里也填上隐私政策 URL

### 用户协议
- [ ] 已在小程序内显示（pages/legal/user-agreement）

## 阶段 10：提交审核（15 分钟）

- [ ] mp.weixin.qq.com → 版本管理
- [ ] 找到刚上传的版本 → 点击「提交审核」
- [ ] 填写：
  - [ ] 功能页面截图（5 张）
  - [ ] 类目（教育 → 在线教育）
  - [ ] 服务类目资质（个人通常无需）
  - [ ] 审核备注：核心功能 + 目标用户
- [ ] 点击「提交」

## 阶段 11：等待审核（1-7 天）

- [ ] 等待微信审核
- [ ] 如被拒，根据反馈修改 + 重新提交
- [ ] 通过后点击「发布」

## 阶段 12：上线后

- [ ] 用户反馈监控
- [ ] 数据分析（漏斗 / 留存）
- [ ] 计划下一版本迭代
