## 推荐尺寸

- **iPhone 6**：750 × 1334 px（**推荐**，通用）
- **iPhone X**：1125 × 2436 px（高端机型）
- **Android**：1080 × 1920 px 或类似

## 制作方法

### 方法 A：真机截屏（推荐）
1. 微信开发者工具 → 编译
2. 点击"预览" → 用微信扫码 → 真机打开
3. 截屏（iPhone 同时按电源 + Home；Android 按电源 + 音量下）

### 方法 B：开发者工具内置截屏
1. 微信开发者工具 → 模拟器
2. 在右侧选择设备型号（如 iPhone 6）
3. 点击"截屏"按钮 → 自动保存

### 方法 C：自动化（高级）
用 Puppeteer / Playwright 自动化跑小程序（仅支持 H5 模式）。

## 截屏检查清单

每张截图必须满足：

- [ ] 尺寸符合规范（750×1334 或更大同比例）
- [ ] 内容清晰、文字可读
- [ ] 包含真实学习数据（不要全是 Mock 占位）
- [ ] 没有测试数据水印 / TestFlight 标记
- [ ] 主题色与品牌一致（科技极简：黑/白/灰 + 蓝绿点缀）

## 上传步骤

1. mp.weixin.qq.com → 版本管理 → 提交审核
2. 找到"功能页面截图"区域
3. 拖入 5 张图片
4. 顺序：首页 → 选词书 → 复习 → AI 解释 → 统计
5. 填写每张图的"页面标题"（如"首页"、"复习页"）

## 审核被拒常见原因（截图相关）

| 原因 | 修复 |
|---|---|
| 截图与实际功能不符 | 用真实运行的截图，不要用 mockup |
| 截图太小看不清 | 提高分辨率 |
| 截图含敏感信息 | 检查截图无内部测试数据 / 用户手机号 / 真实邮箱 |
| 截图数量不足 | 必须 5 张 |
