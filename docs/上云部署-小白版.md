# 上云部署 · 小白版步骤（阿里云 / 腾讯云）

> 目标：把 Vocabulary Agent 部署到云服务器，电脑关机了手机也能用。

---

## 第一步：买服务器（10 分钟）

### 方案 A：腾讯云轻量应用服务器（推荐，便宜）

1. 打开 https://cloud.tencent.com/product/lighthouse
2. 点「立即选购」
3. 选择：
   - **地域**：离你近的（如广州/上海/北京）
   - **镜像**：**Ubuntu 22.04 LTS**（重要！）
   - **套餐**：2核 2G（新用户常有优惠）
   - **时长**：先买 1 个月试试
4. 设置 **root 密码**（记下来！）
5. 购买完成 → 控制台 https://console.cloud.tencent.com/lighthouse 看到 **公网 IP**

> ⚠️ 腾讯云需要额外开放端口（见下方"开放端口"）

### 方案 B：阿里云轻量应用服务器

1. 打开 https://www.aliyun.com/product/swas
2. 镜像选 **Ubuntu 22.04**，套餐 2核 2G
3. 设置 root 密码，购买

---

## 第二步：开放端口（腾讯云必做，1 分钟）

腾讯云轻量服务器默认只开 22（SSH）端口，需手动放行 80：

1. 控制台 → 你的服务器 → **防火墙** 标签页
2. 点「添加规则」→ 端口 `80`，协议 `TCP`，策略 `允许`
3. 保存

> 阿里云在「安全组」里放行 80/443，方法类似。

---

## 第三步：上传项目（在你自己电脑 PowerShell）

买完服务器后，在**你自己的电脑**执行：

```powershell
# 1. 打包项目（排除 node_modules 等大文件）
cd C:\AppSoft
Compress-Archive -Path vocabularyagent -DestinationPath vocab.zip -Force

# 2. 上传到服务器（会提示输入 root 密码）
scp vocab.zip root@你的公网IP:/root/

# 3. SSH 登录服务器
ssh root@你的公网IP
```

> 提示：`你的公网IP` 换成实际 IP，如 `43.123.45.67`

---

## 第四步：在服务器上部署（登录后执行）

```bash
# 1. 解压
cd /root
apt install -y unzip
unzip vocab.zip -d vocab-agent
cd vocab-agent

# 2. 配置 DeepSeek Key
cp .env.production.example .env.production
nano .env.production
# 把 DEEPSEEK_API_KEY=sk-xxx 改成你的真实 key
# Ctrl+O 保存，Ctrl+X 退出

# 3. 一键部署（自动装 Docker + 构建 + 启动）
bash tools/deploy/deploy-aliyun.sh
```

> 脚本虽然叫 deploy-aliyun，但阿里云/腾讯云通用（就是装 Docker + 启动容器）。

部署完成后，浏览器/手机访问 `http://你的公网IP` 即可使用！

---

## 第五步：绑定域名 + HTTPS（可选，建议做）

1. 买域名（阿里云/腾讯云，几十元/年）
2. 域名解析：A 记录指向服务器公网 IP
3. ICP 备案（国内必须，7-20 天）
4. HTTPS 证书：
   ```bash
   apt install -y certbot python3-certbot-nginx
   certbot --nginx -d your-domain.com
   ```

## 常见问题

| 问题 | 解决 |
|---|---|
| 服务器连不上 80 端口 | 控制台「防火墙/安全组」放行 80 和 443 |
| 部署报错 | 把报错信息发给我，我帮你远程修 |
| 想更新代码 | 重新上传 + `bash tools/deploy/deploy-aliyun.sh` |
| AI 返回余额不足 | 去 DeepSeek 充值 |
| 手机访问不了 | 确认防火墙放行 80 + 用公网 IP 访问 |
