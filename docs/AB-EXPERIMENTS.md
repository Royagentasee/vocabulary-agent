## 1. AI 解释布局（ai_explain_layout）

### 假设
**H1**：内联展开（直接在复习页内显示）比点击展开（默认折叠在按钮后）有更高的使用率。

### 变体
- **A（控制）**：折叠在按钮后（当前默认）
- **B**：内联展开（在复习页卡片内直接显示）
- **C**：侧边栏抽屉（从右侧滑出）

### 衡量指标
| 指标 | 公式 | 期望 |
|---|---|---|
| **AI 解释曝光率** | 看过 AI 解释的会话 / 总会话 | B > A > 20% |
| **AI 解释点击率** | 点过 AI 解释按钮 / 看到按钮 | B > A > 30% |
| **学习完成率** | 完成复习 / 开始复习 | B ≥ A（不影响） |

### 流量分配
- 灰度：先 10%，观察 1 周
- 全量：33% / 33% / 34%

### 决策标准
- **采纳**：B 方案 AI 解释曝光率显著高（+5% 以上）且学习完成率不降
- **拒绝**：曝光率提升但完成率下降（说明影响主流程）
- **继续观察**：差异不显著（<5%）

## 2. 评分按钮配色（rate_button_colors）

### 假设
**H1**：暖色（红/橙）按钮点击率高于冷色（蓝/绿），因为更突出。

### 变体
- **A（控制）**：暖色（忘记=红/困难=橙/良好=蓝/简单=绿，当前）
- **B**：冷色（忘记=深红/困难=深橙/良好=蓝紫/简单=青绿）

### 衡量指标
| 指标 | 公式 | 期望 |
|---|---|---|
| **评分完成率** | 评分点击 / 卡片展示 | B ≥ A |
| **评分平均时长** | 评分耗时 | B ≤ A（更快） |

### 流量分配
- 50/50 A/B 测试

## 3. 首页引导文案（home_intro_variant）

### 假设
**H1**：展示具体数据（如"已帮助 100 万用户记住 1000 万词"）比抽象描述更能转化。

### 变体
- **A（控制）**：「AI 陪伴，考点驱动，让每个单词都记得更牢」（当前）
- **B**：「已帮助 100 万备考者记住 1000 万单词」
- **C**：「基于 FSRS 算法 + AI 私教，平均提分 15+」

### 衡量指标
| 指标 | 公式 | 期望 |
|---|---|---|
| **注册转化率** | 注册 / 访问首页 | B > A > 10% |
| **首次复习完成率** | 完成复习 / 注册 | C > A > 5% |

### 流量分配
- 33% / 33% / 34%

## 4. 新用户默认模式（new_user_default_mode）

### 假设
**H1**：新用户更适合从「看英忆中」开始（最简单），而不是「拼写听写」。

### 变体
- **A（控制）**：看英忆中（当前默认）
- **B**：拼写听写
- **C**：例句填空

### 衡量指标
| 指标 | 公式 | 期望 |
|---|---|---|
| **7 日留存率** | 7 日活跃 / 注册 | A > B,C > 5% |
| **首日完成复习数** | 当日复习 / 注册 | A > B,C |

## 5. 实验实施流程

### 5.1 上线前
1. 定义假设 + 主要指标
2. 配置 SDK（@vocab-agent/sdk-ab）
3. 设置白名单（团队成员强制分配）
4. 设计埋点（曝光 + 转化）

### 5.2 灰度阶段
1. 5% 灰度，1 周观察
2. 检查无技术异常 → 10% 灰度
3. 持续观察至流量稳定

### 5.3 全量阶段
1. 50/50 A/B 测试，2-4 周
2. 每天检查显著水平
3. 决策（采纳 / 拒绝 / 继续观察）

### 5.4 决策后
1. 采纳：全量推广
2. 拒绝：回滚到控制组
3. 继续观察：调整流量重新测试

## 6. 数据收集

### 6.1 客户端埋点

通过 `sdk-ab` 的 `onEvent`：

```ts
import { getABClient } from '@vocab-agent/sdk-ab'

const client = getABClient()
client.onEvent((event) => {
  // 上报到埋点系统（神策 / 友盟 / 自建）
  analytics.track(event.type, {
    experiment_key: event.experimentKey,
    variant: event.variant,
    event_name: event.eventName,
    properties: event.properties,
  })
})
```

```ts
// AI 解释查看

// 注册
client.track('home_intro_variant', 'user_registered')
```

## 7. 显著性检验

最小样本量 = 16 × p × (1-p) / (δ²)
- p = 基准转化率（0.1 ~ 0.3）
- δ = 期望最小可检测差异（0.05）

例：基准 10%，期望检测 5% 差异 → 最小样本 5,760

**结论**：每个变体至少 5,000-10,000 用户才能得出可靠结论。

## 9. 注意事项

1. **同时运行的实验** ≤ 3 个，避免干扰
2. **同一用户不应在多个实验中冲突**
3. **新用户默认进入所有实验**（除非显式排除）
4. **重大 UI 改动不应通过 A/B 测试**（用产品调研）
5. **隐私合规**：A/B 实验数据属于用户数据，需符合隐私政策
