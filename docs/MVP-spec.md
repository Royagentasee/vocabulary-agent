# MVP 详细规格说明（v0.5）

> 本文是 PRD 第 7.1 节的展开，用于设计、研发、测试直接落地。所有"不做"的项请勿私自添加。

## 1. 范围
- **目标用户**：备考 GRE / 雅思 / 托福 / SAT 的英语学习者
- **平台**：Web（PWA），桌面端浏览器优先，移动端 Web 体验需合格
- **工期**：8–10 周
- **团队**：1 全栈 + 1 前端 + 1 AI/算法 + 0.5 设计

## 2. 用户流程
1. 首次进入 → 选目标考试（GRE / 雅思 / 托福 / SAT） → 选词书（高频 5000 / 官方词书） → 设置每日词量（30 / 45 / 60） → 可选填考试日
2. 进入「今日学习」→ 新词学习（看英忆中）→ 释义卡可点击「AI 详解」
3. 完成后进入「今日复习」→ FSRS 推送的复习队列 → 错词自动入错词本
4. 学习结束展示数据：今日新学 / 复习 / 准确率 / 连续打卡天数 / 距考试天数
5. 错词本可一键「重考」

## 3. 功能清单

### 3.1 选词与设置
- 选考试目标（单选）
- 选词书（高频 5000 / GRE 核心）
- 选每日词量（30 / 45 / 60）
- 选考试日（可选）
- 学习时段提醒（可选，可关闭）

### 3.2 背词主流程
- **看英忆中**：单词 + 音标 + 音频 → 点击「显示释义」→ 4 档评分（不认识 / 困难 / 良好 / 简单）→ FSRS 计算下次复习时间
- **AI 详解入口**：每张词卡有「AI 详解」按钮，调用 LLM 生成补充解释（词根 / 近反义 / 考点）
- **音频播放**：真人发音，可重播

### 3.3 复习流程
- FSRS 推送的复习队列（默认 1.5x 屏幕一卡）
- 同样的 4 档评分
- 标记为"不认识"自动入错词本
- 错词本可重考

### 3.4 激励
- **打卡日历**：当月日历视图，已学日期高亮
- **连击**：连续学习天数，缺失需补卡
- **考试倒计时**：首页顶部"距考试 N 天"
- **今日进度**："今日还差 N 词完成达标"

### 3.5 数据
- 记忆曲线：最近 30 天每日记忆保留率折线图（1 张图）

### 3.6 词书
- 高频 5000（ECDICT 开源数据）
- GRE 核心（官方授权，待谈；未授权前用 ECDICT 替代集）
- 词条字段：中文释义 + 音标 + 音频 + 词根 + 例句 + 考频
- 暂不做：词组搭配、派生词、近反义、考点标签

## 4. AI 能力
- **AI 释义 / 详解**
  - 输入：单词 + 词条基础字段
  - 输出：词根拆解 + 常见搭配 + 考试要点（≤ 200 字）
  - 接口：内部 LLM 网关，按用户调用计费
  - 限速：每用户每日 ≤ 30 次
- **AI 错因归因**
  - 触发：错词入错词本
  - 输入：单词 + 错误历史 + 同类易混词
  - 输出：错因标签（拼写 / 词义混淆 / 语境误判）+ 1 句建议
  - 限速：每用户每日 ≤ 10 次

## 5. 数据模型（核心表）
- `User`：id、邮箱、目标考试、每日词量、考试日、注册时间
- `Wordbook`：id、名称、词数、来源（官方/开源）
- `Word`：id、wordbook_id、word、phonetic、audio_url、meaning、root、example、frequency
- `StudyCard`：id、user_id、word_id、stability、difficulty、due_at、reps、lapses、last_review
- `ReviewLog`：id、card_id、rating、reviewed_at
- `ErrorNote`：id、user_id、word_id、reason_tag、ai_advice、created_at
- `Streak`：user_id、date、new_count、review_count、accuracy

## 6. 接口（关键）
- `GET /api/today` —— 返回今日新词 + 复习队列
- `POST /api/review` —— 提交一次复习评分
- `POST /api/ai/explain` —— AI 详解
- `POST /api/ai/error-reason` —— AI 错因
- `GET /api/stats/memory-curve` —— 30 天记忆曲线
- `GET /api/me` —— 用户设置

## 7. 非功能
- 首屏 < 1.5s，AI 释义 P95 < 3s
- 离线：当日复习队列本地缓存
- 隐私：学习数据可导出 / 删除
- 浏览器：Chrome / Safari / Edge 最近 2 个大版本

## 8. 验收 / 成功标准
- **功能**：上述 3.1–3.6 全部跑通
- **性能**：核心页 LCP < 1.5s，AI P95 < 3s
- **数据**：注册 → 首次学习转化 ≥ 80%
- **留存**：7 日留存 ≥ 45%
- **AI 价值**：AI 释义 / 错因 月活渗透率 ≥ 50%
- **付费信号**：词书页 → 付费转化 ≥ 8%

## 9. 不做（明确）
- 拼写听写、例句填空
- AI 造例、AI 语音陪练
- 积分体系、好友 PK、考友群、督学老师
- iOS / Android / 小程序 / 桌面端
- 多语种与无障碍深度适配
- 词组搭配、派生词、近反义、考点标签

## 10. 风险与回退
- **官方词书授权未谈妥**：先用 ECDICT 替代集，词书页标注"精选版"
- **AI 成本超预算**：AI 详解限速 30 次/日，必要时降到 15 次
- **FSRS 调参不佳**：保留"经典 SM-2"作为算法 A/B 备选
