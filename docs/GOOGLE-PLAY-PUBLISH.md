## 1. 注册 Google Play Console

1. 访问 https://play.google.com/console
2. 用 Google 账号登录
3. 同意条款 → 支付 **$25** 一次性注册费（终身有效）
4. 完成开发者资料：
   - 开发者名称
   - 电子邮件地址
   - 电话号码
   - 网站（可选）

## 2. 创建应用

1. Play Console → "创建应用"
2. 填写：
   - **默认语言**：简体中文 / English
   - **应用名称**：Vocabulary Agent
   - **应用类型**：应用
   - **免费还是付费**：免费
3. 同意声明 → 创建

### 内容分级

1. Play Console → "内容分级"
2. 填写问卷（教育类应用通常为 E 级 / Everyone）

### 目标受众与内容

1. **目标年龄**：选"18+" 或 "13+"（教育类避开儿童标签可加快审核）
2. **新闻应用**：否
3. **是否含广告**：否
4. **应用是否包含用户生成内容**：否

### 数据安全

必须填写数据安全表单：

| 数据类型 | 是否收集 | 用途 | 是否共享 |
|---|---|---|---|
| 微信昵称 / 头像 | ✅ | 用户身份 | ❌ |
| 学习记录 | ✅ | 核心功能 | ❌ |
| 设备信息 | ✅ | 兼容性 | ❌ |

## 4. EAS Build 打包

```bash
# 在 monorepo 根目录
pnpm install

# 登录 Expo
pnpm --filter @vocab-agent/mobile exec eas login

# 配置 EAS（首次）
cd apps/mobile
eas build:configure

# 打包 Android AAB
pnpm --filter @vocab-agent/mobile build android
# 或: eas build --platform android
```

EAS 会在云端打包，**无需本机有 Android Studio**。完成后下载 AAB。

## 5. Internal Testing

1. Play Console → 测试 → 内部测试
2. 创建新版本 → 上传 AAB
3. 创建测试用户名单（最多 100 个邮箱）
4. 测试链接会自动发送给测试者

## 6. 正式发布

1. Play Console → 发布 → 正式版
2. 上传 AAB（与 Internal Testing 可以用同一份）
3. 填写发布说明
4. 提交审核
5. 等待 1-3 天

## 7. 审核被拒常见原因

| 原因 | 修复 |
|---|---|
| 数据安全表单不完整 | 补全所有数据类型 |
| 缺少隐私政策链接 | 在 Play Store 详情 + 应用内放置 |
| 应用崩溃 | 用 Internal Testing 充分测试 |
| 权限滥用 | 只申请必要的权限 |
| 元数据不合规 | 修改标题 / 描述避免绝对化用语 |

## 8. 持续运营

- **更新版本**：每次修改代码 → EAS Build → Play Console → 新版本
- **数据统计**：Play Console → 统计与分析
- **用户评价**：回复用户评论，维护 4+ 星
- **A/B 测试**：Play Console → 实验管理
