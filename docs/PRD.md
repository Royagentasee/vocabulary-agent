# Vocabulary Agent — 产品需求文档（PRD）

## 0. 文档信息
- **产品名**：Vocabulary Agent
- **产品代号**：vocab-agent
- **版本**：v0.1（草案）
- **目标读者**：产品、设计、研发、测试、运营
- **文档维护**：本文档随需求讨论与迭代持续更新，重大变更记录在文末「变更日志」

## 1. 产品概述
- **目标用户**：备考雅思 / 托福 / GRE / SAT 等高阶英语考试的学习者
- **产品定位**：**AI 个性化辅导型** —— 把大模型作为“伴随式私教”，承担拆词、组句、复述、口语陪练、错因分析等角色
- **核心价值主张**
  1. **考点驱动**：词条与考试考点强绑定，词根词缀、近义辨析、真题语境一站式呈现
  2. **AI 陪练**：基于 FSRS 安排复习节奏，再用 LLM 进行解释、造句、口语对练
  3. **全端覆盖**：Web（PWA）+ iOS / Android（跨端）+ 微信小程序 + 桌面端
- **产品调性**：科技极简（专业型）—— 留白多、动效克制、突出 AI 能力，不刻意人格化

## 2. 角色与典型场景
- **自学者 / 备考党**：每日 30 分钟、60 词，需要明确进度感与考点覆盖
- **冲分党 / 考前冲刺**：高强度、集中复习，需要错题归因与高频考点反复练
- **口语 / 面试备考**：需要 AI 陪练、模拟面试、表达评估
- **机构 / 老师 / 学习小组负责人**：需要查看成员进度、布置任务、轻量督学

## 3. 核心功能需求

### 3.1 学习功能与记忆算法
- **间隔重复算法**：采用 **FSRS**（基于 DSR 模型），通过独立算法服务运行
- **背词模式**（四件套）：
  - 看英文回忆中文（默认主流模式）
  - 拼写听写（强主动回忆，针对写作）
  - 例句填空（真题语境填词）
  - AI 对话练习（用刚学的词与 AI 进行 60s 口语对练）
- **节奏**：稳健备考型，默认每日 30–60 词，可根据考试日倒推总词量
- **动态调整**：根据近期表现（评分、遗忘率）由 FSRS 自动调整下次复习时间
- **学习闭环**：新词学习 → 当日复习 → 1/3/7/30 天间隔复习 → 错词本重考

### 3.2 内容与词库
- **词库来源**（四源并用）：
  - 权威词典：柯林斯 / 朗文 / 牛津等高阶释义与真人例句
  - 考试语料库：近 5–10 年雅思 / 托福 / GRE 真题语料
  - 开源词库：ECDICT 等打底，覆盖基础词条
  - AI 生成补充：词根拆解、近反义辨析、语境例句（人工抽检）
- **词条字段**（全要）：
  - 中文释义 + 英英释义 + IPA 音标 + 真人发音音频
  - 词根词缀拆解 + 近义词 / 反义词 / 易混词
  - 考试标签（GRE 高频 / 雅思 7+ 等）+ 考频 + 难度分级
  - 真题例句（含来源）+ 词组搭配 + 派生词
- **预置词书**：官方词书（GRE 核心 / 雅思真词汇 / 托福红宝书等），可购买授权
- **用户生词本**：支持从阅读 / 听力 / 浏览器插件 / 拍照中手动 / 自动取词

### 3.3 激励与社交
- **个人激励**（四件套）：
  - 打卡 / 连续学习（连击日历、补卡机制）
  - 考试倒计时 + “今天离达标还差 N 词”进度条 + 里程碑徽章
  - 可视化记忆曲线、能力雷达图、错词本可重考
  - 积分体系：可兑换会员、虚拟道具
- **社交**（全要）：
  - 考友群组：按目标考试 / 考试日期 / 地区匹配
  - 好友 PK 与单词对战排行榜（可隐身上线）
  - 督学老师 / 班主任：布置任务、查看进度、发送提醒
  - 学习分享：错词本、笔记、词根漫画可生成海报分享
- **调性**：科技极简、突出能力与数据，不堆砌游戏化元素

### 3.4 交互与体验
- **AI 人设**：**中性专业口吻**，与“科技极简”调性一致，不刻意人格化
- **AI 能力**（全要）：
  - 拆词 / 释义 / 详解：基于词根词缀、近反义、考点进行结构化解释
  - 造句 / 复述 / 表达训练：主题作文、复述反馈
  - 口语陪练：语音对练、发音评分、模拟面试 / 口语考试
  - 错题归因 / 个性化推荐：错因分析 + 下一步学习建议
- **体验细节**（全要）：
  - 极简手势（左右滑、点按）+ 减少按钮
  - 专注 / 沉浸学习模式（关闭社交通知、全屏）
  - 跨端无缝同步（Web / 手机 / 桌面进度实时一致）
  - 无障碍 / 多语种：读屏适配、色弱友好、界面多语言

## 4. AI 能力专题
- **大模型定位**：伴随式私教
- **核心能力**：拆词释义、造句、复述、口语陪练、错因归因
- **数据与 RAG**：词库 / 真题语料 / 个人学习记录 作为检索源
- **隐私**：学习内容脱敏存储，对话记录可一键清除

## 5. 非功能需求
- **性能**：核心页面首屏 < 1.5s；AI 解释接口 P95 < 3s
- **可用性**：全年 SLA 99.9%；离线可继续复习（本地缓存复习队列）
- **隐私**：符合 GDPR / 中国个人信息保护法；对话与学习数据可导出 / 删除
- **可扩展性**：算法服务、词库服务、AI 网关可独立伸缩
- **跨端**：Web（PWA）+ iOS / Android（建议 React Native / Flutter）+ 微信小程序 + 桌面端（Electron / Tauri 评估）

## 6. 指标与成功标准
- **学习成效**：7 日留存 ≥ 50%、30 日留存 ≥ 25%、复习完成率 ≥ 70%
- **能力提升**：用户自评考分提升 / 模拟考正确率提升（需对接合作机构）
- **AI 价值**：AI 解释 / 陪练功能月活渗透率 ≥ 60%、NPS ≥ 50
- **商业**：付费转化率、ARPU、续费率（具体数值待定）

## 7. 里程碑与版本规划

### 7.1 MVP（v0.5）—— 🟢 极简 MVP
**目标**：用 Web 单端在 8–10 周内验证三大核心假设（H1 AI 留存 / H2 词书付费 / H3 FSRS 复习）
**工期**：8–10 周 ｜ **团队**：1 全栈 + 1 前端 + 1 AI/算法 + 0.5 设计

**必须上**
| 模块 | 内容 |
|---|---|
| 背词 | 看英忆中（默认主模式） |
| 词库 | 高频 5000（ECDICT 开源）+ 1 本官方词书（GRE 核心，授权待谈） |
| AI 能力 | AI 释义 / 详解 + AI 错因归因 |
| 算法 | FSRS v4，独立算法服务 |
| 激励 | 打卡 + 连击日历 + 考试倒计时 + 错词本可重考 |
| 数据 | 记忆曲线（最简折线图，暂不做雷达） |
| 平台 | Web（PPA）单端 |

**验收标准**
- 7 日留存 ≥ 45%、AI 释义月活渗透率 ≥ 50%
- 词书页 → 付费转化 ≥ 8%
- 复习完成率 ≥ 65%
- 性能：首屏 < 1.5s、AI 释义 P95 < 3s

**显式不做**（推迟到 V1.0+）
- 拼写听写、例句填空
- AI 造例、AI 语音陪练
- 积分体系、能力雷达、好友 PK、考友群、督学老师
- iOS / Android / 小程序 / 桌面端
- 多语种与无障碍深度适配

### 7.2 V1.0（增长期）
- iOS + Android 跨端
- 拼写听写 + 例句填空 补齐背词四件套
- AI 对话练习（语音陪练）
- 考友群组 + 好友 PK
- 错题归因 + 可视化能力雷达

### 7.3 V2.0（生态期）
- 微信小程序 + 桌面端
- 督学老师 / 班主任端
- 考试语料库深度整合 + 考频更新机制
- 多语种界面与无障碍完善
- 学习效果衡量（与模考平台合作）

## 8. 风险与开放问题
- **版权风险**：权威词典与官方词书需谈授权，预算与时间未定
- **AI 成本**：语音陪练、个性化推荐对算力消耗大，需设计成本控制策略
- **跨端技术选型**：React Native / Flutter / Tauri / Electron 仍在评估
- **学习效果衡量**：考分提升难以直接归因，需要与考试机构 / 模考平台合作
- **小语种扩展**：当前仅做英语，未来是否扩到日语 / 法语？
- **AI 人设最终方向**：若后续验证“温暖陪练”更能拉留存，可考虑提供人格切换
