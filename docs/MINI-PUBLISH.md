# 微信小程序上架指南

> Vocabulary Agent 微信小程序完整上架流程，预计 **1-2 周** 完成。

## 0. 时间表

| 阶段 | 内容 | 时长 | 费用 |
|---|---|---|---|
| Day 1 | 注册账号 + 主体认证 | 1-3 天 | 个人 0 / 企业 300 |
| Day 2-5 | 完善产品 + 编译 + 体验版 | 3-5 天 | 0 |
| Day 6-8 | 准备上架材料 | 1-3 天 | 0 |
| Day 9-14 | 提交审核 → 上线 | 1-7 天 | 0 |

## 1. 注册小程序账号

1. 访问 https://mp.weixin.qq.com/
2. 点击"立即注册" → 选择"小程序"
3. 填写邮箱（**未被微信注册过**）、密码、验证码
4. 邮箱激活 → 进入主体认证

## 2. 主体认证

### 个人主体（最简，零成本）
- 身份证 + 微信扫码人脸验证
- **限制**：不能做支付、不能获取手机号等敏感接口
- **适合**：MVP / TestFlight 验证

### 企业 / 个体工商户主体
- 营业执照、对公账户（小额打款验证）、法人身份证
- **费用**：认证服务费 300 元/次（年审）
- **能力**：可做支付、获取用户信息

**建议**：先个人主体上线，验证产品后再升级到企业。

## 3. 获取 AppID

主体认证完成后，在"开发管理 → 开发设置"获得：
- **AppID(小程序 ID)**：wx 开头字符串
- **AppSecret(小程序密钥)**：用于服务端调用

把 AppID 填入 `apps/mini/project.config.json`：
```json
{ "appid": "wx1234567890abcdef" }
```

## 4. 配置服务器域名（可选）

如果要让小程序调用 AI 网关的 `/api/ai/explain`：

1. 部署 ai-gateway 到公网（云函数 / VPS / 阿里云函数计算）
2. 域名需要 ICP 备案（个人也可备案）
3. 在"开发管理 → 开发设置 → 服务器域名"配置 `request 合法域名`

**开发期**：微信开发者工具勾选"不校验合法域名、web-view、TLS 版本以及 HTTPS 证书"，可绕过此限制。

## 5. 编译产物

```bash
# 在 monorepo 根目录
pnpm --filter @vocab-agent/mini build
# 产物在 apps/mini/dist/
```

## 6. 微信开发者工具上传

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 扫码登录 → 导入项目 → 选 `apps/mini/dist/`
3. 填写 AppID（或选测试号）
4. 点击右上角"上传" → 填写版本号 + 项目备注
5. 上传成功 → 回到 mp.weixin.qq.com → 版本管理可看到

## 7. 提交审核

1. 登录 mp.weixin.qq.com
2. 版本管理 → 找到刚上传的版本 → 提交审核
3. 填写：
   - **功能页面截图**（5 张，可截图开发工具）
   - **类目**：选"教育 → 在线教育"
   - **服务类目资质**：
     - 个人：通常无需额外资质
     - 企业：可能需《网络文化经营许可证》或《ICP 备案》（看具体类目）
   - **测试账号**：如需登录，提供测试账号
   - **审核备注**：写明核心功能、目标用户

## 8. 常见审核被拒原因

| 原因 | 修复 |
|---|---|
| 类目不对 | 选"教育 → 在线教育"或"工具 → 效率" |
| 用户协议 / 隐私协议缺失 | 在小程序内展示《用户协议》和《隐私政策》 |
| 涉及虚拟支付未走 IAP | 微信小程序虚拟商品必须走微信支付 |
| 缺少必要类目资质 | 个人主体避开"医疗 / 金融 / 教育培训"类 |
| 用户登录态不完整 | 提供"游客模式"可体验核心功能 |

## 9. 发布

审核通过后：
1. mp.weixin.qq.com → 版本管理 → 找到审核通过的版本 → 发布
2. 用户即可通过搜索 / 扫码使用

## 10. 后续维护

- **更新版本**：每次修改代码 → 编译 → 微信开发者工具上传 → 提交审核
- **数据统计**：mp.weixin.qq.com → 统计 → 查看访问 / 用户
- **客服消息**：用户可在小程序内发起客服会话

## ⚡ 快速清单

```powershell
# 1. 注册 + 主体认证（浏览器操作）
#    https://mp.weixin.qq.com/

# 2. 拿到 AppID，填到 apps/mini/project.config.json

# 3. 编译
cd C:\AppSoft\vocabularyagent
pnpm install
pnpm --filter @vocab-agent/mini build

# 4. 微信开发者工具导入 dist/，上传

# 5. mp.weixin.qq.com 提交审核

# 6. 等 1-3 天通过 → 发布 → 上线 ✓
```

## 🆘 遇到问题？

| 问题 | 解决方案 |
|---|---|
| 编译失败：`Cannot find module` | 确认 `pnpm install` 已成功；删除 `apps/mini/dist/` 重试 |
| 上传失败：`ext.json 未配置` | 暂可忽略（首次上传） |
| 审核被拒"涉及教育" | 切换类目到"工具 → 效率" |
| AI 接口无法访问 | 小程序要求 HTTPS + ICP 备案，要么部署到正式域名，要么用云函数代理 |
| 用户登录问题 | 提供"游客模式" + 后续引导注册 |
