# Vocabulary Agent 隐私政策

**最后更新日期**：2026 年 X 月 X 日

**生效日期**：2026 年 X 月 X 日

---

Vocabulary Agent（以下简称"我们"）深知个人信息对你的重要性，并承诺按照法律法规要求，保护你的个人信息安全。鉴于此，我们制定本《隐私政策》并提示：

在使用我们的服务前，请你务必仔细阅读并透彻理解本政策，在确认充分理解并同意后再开始使用。

## 1. 我们收集的信息

### 1.1 你主动提供的信息

| 信息类型 | 用途 | 是否必须 |
|---|---|---|
| 微信昵称 / 头像 | 展示个人资料 | 是 |
| 学习记录（单词、复习评分、错词） | 提供核心学习服务 | 是 |
| 学习目标（考试类型、考试日期） | 个性化学习建议 | 否 |

### 1.2 我们在你使用服务时自动收集的信息

| 信息类型 | 用途 | 保留期限 |
|---|---|---|
| 设备信息（设备型号、系统版本） | 兼容性优化 | 仅本地 |
| 日志信息（访问时间、操作记录） | 故障排查与安全分析 | 30 天 |
| 网络信息（IP 地址、网络类型） | 反作弊与安全分析 | 30 天 |

### 1.3 我们不收集的信息

- 通讯录、短信、通话记录
- 地理位置（精确位置）
- 摄像头 / 麦克风权限（仅在使用 AI 口语陪练功能时申请）
- 任何与核心学习功能无关的信息

## 2. 信息使用

我们仅将收集的信息用于以下用途：

1. **提供核心学习服务**：词条展示、复习调度、AI 解释、学习报告
2. **改进服务质量**：分析使用数据，识别并修复问题
3. **安全保障**：识别异常登录、防范安全风险
4. **响应你的请求**：处理你提交的反馈与建议

**我们承诺**：
- 不会用于任何商业广告投放
- 不会出售给任何第三方
- 不会超出本政策范围使用

## 3. 信息共享

我们仅在以下情况下共享你的信息：

| 接收方 | 共享信息 | 目的 |
|---|---|---|
| 微信平台 | 加密的 OpenID | 登录鉴权 |
| 云服务提供商 | 加密存储的学习记录 | 数据托管 |
| 监管部门 | 法律要求的数据 | 配合监管 |

**第三方服务清单**：

| 服务 | 用途 | 隐私政策 |
|---|---|---|
| 微信开放平台 | 登录鉴权 | https://weixin.qq.com/agree?lang=zh_CN |
| DeepSeek | AI 单词解释 | https://deepseek.com/privacy |
| 阿里云 / 腾讯云 | 数据托管 | https://terms.aliyun.com 或 https://cloud.tencent.com/document |

## 4. 信息存储

- **存储地点**：中华人民共和国境内（境外用户数据按当地法规处理）
- **存储期限**：账号有效期内持续保留；账号注销后 30 天内删除
- **加密措施**：传输层 TLS 1.2+，存储层 AES-256

## 5. 你的权利

你对自己的个人信息享有以下权利：

| 权利 | 如何行使 |
|---|---|
| **查看权** | 在小程序内"我的 → 学习数据"查看 |
| **更正权** | 自行修改昵称、头像、学习目标 |
| **删除权** | "我的 → 注销账号"可一键删除 |
| **撤回同意** | 关闭对应权限（如位置、摄像头） |
| **投诉举报** | support@vocabulary-agent.com |

## 6. 未成年人保护

- 本服务面向 14 周岁及以上用户
- 14 周岁以下未成年人使用本服务须取得监护人同意
- 我们已建立专门机制保护未成年人信息

## 7. AI 数据的特别说明

7.1 你使用 AI 解释功能时，输入的单词 / 上下文会发送给 AI 服务提供商（DeepSeek）以生成解释。
7.2 **我们承诺**：不会将这些数据用于模型训练。
7.3 AI 服务提供商的数据处理遵循其自身隐私政策（见上文）。

## 8. 政策更新

8.1 我们可能根据业务变化或法律法规更新本政策。
8.2 重大变更将通过应用内通知等方式告知你。
8.3 继续使用本服务视为同意变更后的政策。

## 9. 联系我们

如对本政策有任何疑问：

- **邮箱**：privacy@vocabulary-agent.com
- **小程序内反馈**：通过"我的 → 意见反馈"
